Hi, I'm Matt. I build full-stack web apps and controller-first Windows software.

I'm a self-taught developer who learns by building. My biggest project right now is ControllerPlayground, a Windows gaming shell designed for the couch: a WinUI 3 app in C# sitting on top of a native C++ input layer I wrote over Microsoft GameInput.

On the web side I build with React, Node.js, Express and PostgreSQL, from REST APIs with authentication to a full e-commerce flow with Stripe payments. I've completed Codecademy's Computer Science career path and am finishing the Full-Stack Engineer path.

Away from the editor, I'm usually playing games or tinkering with home server setups.
